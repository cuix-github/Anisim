# 深色背景撞水实验：当前候选的累计对照

2026-10-24，Xue 要求回到最初的深色背景水柱撞水实验，亲自观察累计修改的视觉
影响，并延长到水面接近静止。本轮是明确授权的视觉诊断，不替代仍未完成的
几何体积标定、留出场景和三维验收。没有修改求解器、生产默认值或旧缓存。

## 固定场景与判定

64×80×1、初始 20,480 个主粒子，其中水粒子 6,008；dt 为 float32 的
0.0025 秒。初始位置、速度、类型、半径、喷雾与逃逸标记逐数组检查，与旧
240 秒实验完全相同。初始种子 1，发射种子 137，重力和 FLIP 混合比例不变。
没有额外阻尼、平滑或为了静止而调参数。1 格对应 1 米，是独立诊断尺度。

当前组合：`phase_model=2`、`escape=2`、`transport_model=3`、
`droplet_transfer_model=1`、`volume_model=1`、`volume_tau=.5`；
`emit_model=2`、每事件 16 个独立液滴、原 rate=.6 和梯度阈值 2；ST/adapt 关闭。
新主液滴契约要求 `droplet_evap_k=0`。目前这是共享端口，**辅助喷雾的蒸发也被
关闭**，不能假称旧、新两组只有某个数值修复不同。

最多运行 240 秒，每 20 秒保存完整检查点；每 0.2 秒保存显示状态。沿用旧
10 秒窗口的全部近静止条件：主水 RMS≤.05 格/秒、速度 P99≤.2 格/秒、
动能≤本次采样峰值的 1e-4、每 2 格横向列的水面高度代理变化≤.25 格。
窗口包含真正的检查点末态。这个高度代理不是重建网格，也不是体积测量。
达到全部条件才提前停止；达到最长时长仍不满足则如实记录。

运行前复现旧 off/log 控制，每组 13 个状态数组逐位相同。第一段结束后以
真实完整状态核验 80 步与 40+40 步续跑，不能只把位置当作检查点。
每一步检查压力真实残差、喷雾出生/回水账目；每个保存状态核验主水粒子数。

## 从早期到现在，哪些真的发生了变化

这些是不同阶段的工作，不能全部称为“语言精度修复”。

| 阶段 | 改变了什么 | 当前视频的关系 |
| --- | --- | --- |
| 旧辅助喷雾 | 原本已有大梯度处单粒子发射；并非直到本轮才出现喷雾开关 | 历史模式保留，当前未选用 |
| 事件发射与飞行 | 每事件生成多个独立位置/速度/半径的液滴；数量与期望事件体积分开控制；中点空气采样、子步长与阻力积分、生灭记账 | 已启用；当前没有加大发射率或每事件数量 |
| 相场实验纠正 | 最初 NumPy 和 C++ 使用了不同相场；后来显式统一质量相场与纯相面规则，并修正独立 float32 动量端口的 Python 舍入 | 当前选 phase 2；不能将最早比较称为公平的双实现比较 |
| 逃逸判定 | 从对侧相粒子计数改为相场阈值 | 当前选 escape 2；阈值仍为 .3，没有为此视频调节 |
| 速度推进 | 增加水侧速度外推与局部 RK3 | 当前选 transport 3 |
| 气泡与主水滴生命周期 | 实验路径按论文删除被分类的气泡；独立主液滴候选在空中退出网格沉积，回水恢复数值权重；修正该模式下小半径主水粒子的意外删除 | 当前启用；单向转移和回水细节是明确的实现选择，不冒称作者代码 |
| 粒子采样密度反馈 | 先试 log 形式，空计数处被拒绝；随后有限形式支持零计数，并满足封闭域散度兼容条件 | 当前选有限形式；不是几何体积守恒证明，也不是新压力解算器 |
| 其他探索 | 收紧压力容差、缩小 dt、旧/新耦合对照、相场中间公式等诊断 | 不把所有试验同时启用；本次没有进一步改变这些参数 |

旧喷雾与 ST/adapt 联动曾修复索引重排错误；这次 ST/adapt 关闭，该修补不能
用来解释本次图像差异。旧生产海浪也不会因为实验选项存在而自动获得这些变化。

## 如何看对照

`original_vs_current_20s.mp4` 对比最早保存的 C++ 深色背景 20 秒实验和当前
候选。**那份最早的视频已经开启每事件 16 粒的发射**，不是“完全没有辅助
喷雾”的对照。它使用旧相场/计数分类/推进/转移等规则。

`previous_vs_current_long.mp4` 对比上次已经采用相场分类的长实验和当前组合。
旧实验是 phase 2、escape 2，尚未启用新推进、独立主液滴和密度反馈；保留
旧蒸发系数。这是两个固定版本的累计差异，不是隔离某一变量的因果试验。

所有画面用同样的视野、点大小、蓝水/灰空气/橙逃逸水/白辅助喷雾配色。
标记大小用于辨认，不表示液滴真实半径。实时视频按模拟时间 1:1 播放，
4 倍版本明确标注；没有插值或重复静帧来暗示水已平静。

入口：[运行脚本](../experiments/current_plunge_2d.py)、
[只读可视化](../experiments/inspect_current_plunge.py)。
本地输出 `out/runs/current_plunge_20261024/`，包含 job、源码/DLL 哈希、
逐步日志、检查点、原始数组和视频。小型结果另记入 results，视频不上传公开仓库。
