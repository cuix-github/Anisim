## 冻结的数学事实及尚需落实的选择

| 环节 | 来源/契约 | 当前事实 |
| --- | --- | --- |
| 相场 | PF §3.2–3.3，Eq.6/7、纯相面修正 | phase=2 有局部 gate；cell-centre 取样是实现选择 |
| 压力 | PF §3.5 Eq.8：dt div(beta grad p)=div(u*)+c_div | 当前 RHS 只有 -div(u*)/dt；本代码解正半定的负 Laplacian，符号需一起核对 |
| 体积修正 | 同页说明以目标粒子密度 rho0 修正，并引用 Losasso 2008 | PF 没有给出完整 c_div 离散式；不能声称任意一个密度反馈就是作者代码 |
| 引用公式 | Losasso 2008 §3，第 3 页 Eq.5 后：T=log(n_target/n_current)/tau | 目标速度散度为 -T；tau 是秒，独立于主步长，不是 dt 的别名 |
| 封闭边界 | 离散散度定理：sum(div u)=边界通量=0 | 全 Neumann 压力系统具有常数零空间；非零均值目标散度不相容。处理方式必须写明，不能靠压力迭代“解掉” |
| 密度采样 | 粒子数密度/核权重，与物理水空气质量密度及压缩后的 phi 区别 | 目标标定、墙边支持、空 cell、两相分配、全域兼容处理尚需形成唯一契约 |
| 推进 | PF §3.7 水侧外推、局部 RK3 | transport=1/2/3 有局部验证，尚未与新逃逸规则集成为同一候选；默认仍为 0 |
| 逃逸 | PF §3.4 相场阈值、纯拉格朗日液滴、气泡删除、回水转 FLIP | escape=2 改了分类；主液滴仍全质量 P2G，气泡仍保留；作者未公开的细节不能臆定 |
| 辅助喷雾 | PF §7；独立事件/粒径/阻力/蒸发契约见 spray-events-2d.md | 已发射多个独立液滴；期望体积与数量可分别控制，但非保守碎裂、非分辨率不变发射 |

基础层采用格、格/秒和秒；液滴半径为米，由 metres_per_cell 显式换算。dt 改动时按 PF Eq.13 同时保持粘性代理量；不能只把主步长缩小而暗中增大阻尼。所有 graph 输入按实际 float32 端口舍入。

生产默认 phase=0 与本验收 phase=2 必须分别标记。Bernhard 的私人回复用于研究理解，不把私人邮件/代码写进公开仓库，也不把其指导当作本地程序已经通过验收。

## 有限测试及停止规则

基础层首先做无重力的密度偏差见证和解析压力目标检查，再做既有 48×40、6 秒静水：RMS <= .1 格/秒、COM 漂移 <= .1 格、机械能比例 <= 1.005。相场/压力局部测试沿用原 gate 的固定阈值，真实压力残差须达到请求值；任何拒绝、NaN 或不相容右端都不能算通过。

受控液滴/发射沿用已有 gate 的解析解、独立 ODE 参考和三个步长的检查，包含超过一次事件/步、半径分布、预算截断及生灭账。小案例的每个输出精度门槛由原 gate 固定，不因完整视频分岔降低。

完整撞击复用旧 240 秒结果作基线；只有基础层与生命周期全部集成后，才对最终候选再跑一次。旧近静止门槛和失败结论保留。候选的几何体积测量方法及跨场景物理误差预算必须在该轮运行前冻结；这些目前尚无已通过的标定，不能用水粒子数或高度代理偷换体积。

第二场景使用未参与改参数的落水/回落几何；在选定前不运行它，更不根据结果反复改“留出”场景。同一问题最多两轮定向诊断，仍无法确定时产出一个具体阻塞问题及证据，不无限分支。上游缺口未闭合，下游状态记为 blocked，而非 pass，也不为填满表格启动昂贵实验。

额外粒子团可能降低达到视觉目标所需的主网格成本，但它目前被动跟随两相流，不能补回基础层未解出的卷浪、撞击和空气运动。后续降主网格的研究必须保持物理尺度/粘性代理一致，并按界面采样密度校准发射；当前每个源粒子一个发射率并不自动满足这一点。

## 本轮新检查的预注册

`gates/audit_volume_contract.py` 不改求解器：先复现无重力静止控制，再在同一内部区域放置等总数的过密/过稀粒子，检查两套实现的真实响应。全部粒子远离 .51 格 clamp，排除已知的初始化边界移动。预期见证是当前路径压力/速度为零、密度误差不被纠正；这是缺项证明，不是新修补通过。

另独立检查 Losasso 对数修正的符号与秒单位，并用解析闭壁场检验均值兼容性。直接代入不相容 c_div 的失败必须保留；移除常数分量仅用于展示一种可解的数学投影，不宣称这就是 PF 作者对两相的处理。

来源：PF-FLIP https://ge.in.tum.de/download/Adaptive_Phase_Field_FLIP_preprint.pdf ，Losasso et al. https://jerrytalton.net/research/ltkf-tcspl-08/paper.pdf 。当前完整对应性表见 [paper-correspondence-and-settling.md](paper-correspondence-and-settling.md)，保留所有旧结论。

## 首个体积候选，运行前冻结

`volume_tau=0` 完全保留旧路径；候选为 .5 秒。只允许 uniform 2D、phase=2、escape/emission/transport/ST/adapt 关闭。对全部主水/空气粒子做 Eq.6 cell-centre 数密度 splat；以每格四粒子的规则格点、按相同 .51 格边界限制后的密度作为目标。它修正的是粒子采样密度，不把水空气 1000 倍物理质量差当作压缩误差。

目标散度为 `d=log(n/n_ref)/tau - mean(log(n/n_ref)/tau)`，对应 `c_div=-d`；对本代码的负 Laplacian，RHS 增加 `d/dt`。减均值是满足当前封闭 Neumann 边界的最小二乘常数投影，是明确的实现选择。全域统一的密度倍率被这个投影消去，因此这不是全局绝对体积守恒的证明。目标密度的墙边标定也是实现选择；不是作者的公开离散公式。零或非有限密度拒绝，不偷偷加 epsilon 维持运行。

本轮仅验收局部同输入、受控密度松弛、静水。先复现上一二进制的 13 个最终数组；同输入单步位置误差 <4e-6、速度 <2e-5；1 秒后中心化 log 密度误差 RMS 至少下降 20%；6 秒静水门槛沿用上表。初始化在两臂都先移入合法边界，避免把边界修正的差别归因于体积选项。空支持和不支持组合必须拒绝。未完成这些检查，不运行新的长撞击，更不推广生产默认值。

## 本轮结果与明确停靠点

没有修改 0.5 相位硬阈值、喷雾强度或压力容差。新增的 C++ 修正保持默认关闭，单独作为一个有依据但尚未集成的候选。小型证据在 [volume_contract_20261024.json](../results/volume_contract_20261024.json)，原始输入/输出和前后图在 `out/runs/volume_candidate_20261024/`。

无重力见证中，两套实现对完全相同的密度扰动都保持零速度、零压力残差、位置逐位不变。内部数密度相对未扰动控制约为 -29.7% 到 +80.6% 的偏差没有消失。这证明当前方程不反馈已有采样密度误差，不证明它就是旧视频异常的原因。

封闭域例子中，一半 cell 为目标密度的 .8 倍，另一半为 1.2 倍，平均密度恰为目标，但直接对数目标散度的均值为 -.040822 /秒。相应不相容 RHS 的相对残差有约 .10017 的数学下界，不能靠收紧求解容差消除。常数投影后的独立稠密线性解残差约 1.17e-14，目标散度误差约 1.64e-14。该测试使用 NumPy 独立矩阵，不复用 C++ 压力代码。

## 2026-10-24，完整复读 Losasso 后的有限续验（运行前）

已读 Losasso 2008 正文 §1–7，逐项复核 §3 的连续性推导与对数时间松弛、§4 的 diffuse 限制、§5 耦合区域与边界、§6 海洋案例和 §7 局限。其 §3 有可实现的局部数密度反馈答案；但它不是 PF-FLIP 完整两相修正的源代码说明。§4 为稀疏粒子限制收缩并使用 slip；§5 的 level-set 内部仍设零目标散度，外部 SPH 使用密度反馈。§7 还明确指出界面处邻域不全造成密度估计不可靠。因此，不能把 Losasso 的全套 SPH/level-set 处理等同于 PF 的两相 FLIP，或把对数式施加给所有喷雾。

PF §3.5 指向这类修正，但没有明确给出两相密度采样、逃逸/删除后的目标密度、闭壁兼容条件的离散选择。当前候选只处理不发生转换的全部主水/空气采样点，并明确排除液滴和删除。其减均值只满足 Poisson 可解条件，不证明各相的几何体积守恒。待确认的问题限于这些接口，不扩展成新 SPH 求解器。

本轮 C++ 仅放开已验证体积候选与 transport=1/2/3 的组合；所有默认值、分类阈值、喷雾量、阻尼和压力容差保持原值。Python 通过同一组合继承连接，实际算术分别实现。`gates/validate_base_combination.py` 先逐位复现旧 volume-only 单步，再做两种初态的同输入检查、80 步与 40+40 步完整状态续跑、transport-only 与 combined 的 6 秒静水。位置 <8e-6、速度 <5e-5；静水的 RMS/COM/全段能量门槛沿用旧值。

新增独立几何观测为 cell-centre phi=.5 等值线围成的二维面积：逐线性三角形精确积分，平均两个对角剖分，并报告二者差；边界用最近中心值延伸半格。这是固定重建定义下的面积，不是精确材料体积。先验证解析平面误差 <1e-10 格²，再验证规则粒子平面和圆的面积偏差 <=5%；静水相对初态面积变化 <=2%。初始几何的离散偏差与动态变化分开报告，不以粒子数冒充面积。测量标定失败则不把它用于体积验收。

`gates/audit_particle_lifecycle.py` 用三种固定相场检查普通水、逃逸液滴和逃逸气泡；这是故意可失败的论文验收门。先确保控制水不被删除、液滴有半径，再要求气泡删除。它不改变压力方程，也不把当前代码留住气泡的结果改成通过。若这一基础条款失败，最终集成撞击/留出场景缺少合格候选，状态为 blocked；旧 240 秒失败仍保留。作者问题和明确实现差别分别列出，不能把所有事情都推给作者。

第一次标定在圆半径 8 格处失败：211.3528 对解析 201.0619 格²，误差 5.118%，超过已定 5%。没有修改该门槛或重建参数。后续运行保留独立的代码一致性/静水运动检查，同时完整记录所有标定形状；总体验收仍因标定失败而返回非零。任何面积变化只作该固定重建定义下的观察，不据此给出绝对材料体积守恒结论。这是分开互不依赖的检查，不是把失败改成通过。

第二轮机械子项通过，整体面积验收依旧失败。旧 volume-only 单步的 13 个最终数组完全复现；组合 80 步连续与 40+40 步续跑也有 13 个数组逐位相同。两种初态三步同输入最大位置差 3.81e-6、速度差 1.81e-6，均在已定阈值内。六秒静水 combined 的 C++ RMS .0099921 格/秒、COM 漂移 .012533 格、采样机械能峰值比 1.00009847；固定等值线面积相对初态最大变化 .107742%。这组面积变化是观察值，不消除初始圆面积的标定失败。transport-only 的对应 RMS .0067216；不能说组合让所有指标更好。

一次限定的测量诊断将固定同一个物理圆及域，仅以 h=1,.5,.25 重新采样，不推进模拟。预定判据是面积相对误差单调下降，最细层 <2%；即使通过，也不回填粗层的失败。目的是区分界面离散误差与积分程序错误，不开发另一套表面重建。

喷雾事件的 laws/flight/actual-graph 三组在新 DLL 上全部通过；包含多滴计数/截断账、d² 蒸发、独立阻力运动和三个步长、旧端口兼容。生命周期见证如预期失败：普通水留下且半径零；逃逸水转为有半径的液滴；逃逸气泡标记正确，但仍有一个粒子留下。压力残差均零。此差别无需作者澄清，应按 §3.4 修正，并保留独立前后证据；未修正前不能用喷雾 gate 通过冒充整个生命周期通过。

## 独立修补：phase=2 的逃逸气泡删除（运行前）

修补前通用控制已经落盘：16×12、768 个粒子的满水域含两个独立空气夹杂，零重力/零速度，两个位置均满足 phi>.7。四个 off/legacy/phase-plain/phase-droplet 配置均留下 766 水+2 气。修补后要求 phase 两臂留下 766 水+0 气，所有水位置和质量不变、所有状态数组长度同步；off/legacy 对旧输出逐位相同。另要求分段续跑逐位相同，并复核七种固定相场阈值与三个已有撞击缓存的同输入 Python/C++。原来允许气泡存活的分类测试改为比较删除后的对应索引；原失败证据不覆盖。

## 2026-10-24 后续：独立推导与实验，不等待作者回答

Xue 选择用公开文献、推导和有限测试形成自己的答案。上述三问保留为历史记录，
不再是工作的前置条件。[独立接口实验](independent-interface-closure.md)固定了一个
default-off、uniform 2D、零蒸发的单向主液滴候选，并明确哪些来自论文、哪些是
我们自己的近似。不得把它称作作者未公开的原实现。

取得的结果分成三层。数学上，闭壁目标散度必须总和为零；减均值是均匀单元下
最小平方改动，而全域缩放目标密度会被中心化抵消，不能补偿局部粒子丢失。
局部执行上，实际 Bifrost 与独立 Python 的飞行、转换/回水、续跑和三个共同
撞击输入（关闭密度反馈）通过。静止空气中的独立阻力 ODE 给出了外部判据，
缩小液滴步长使误差持续下降。静水控制的既定运动、能量和材料账也通过。

组合的结论仍为 **不准入**：第一个旧撞击输入已有两个空气区空格，log(n/n0)
在 n=0 处无定义，节点明确拒绝。三个输入排除飞行滴前的空格数为 2/20/13，
之后为 2/20/14；因此不能把首次失败归因于新掩码。这个反例把剩余问题收窄到
稀疏空气区的密度修正规则。没有调 epsilon、改变参考或阈值让它“通过”。

另一个可复现的生命周期缺陷已在新路径修复：主滴即使零蒸发，也可能因抽到
低于 r_min 的半径而被删除。新路径将该气动半径限制到下限并保留材料粒子；
旧路径维持原行为，前后对照及默认关闭回归均保存。这不是用拖曳半径计算真实
代表体积的证明，也不是精确的双向动量守恒模型。

有限实验已给出具体否定结果。完整撞击恢复、独立留出及 3D 不启动；旧近静止
与几何标定失败不被改写。下一轮只针对空/稀疏空气区选择并推导一个修正模型，
再预先固定验收，不从当前结果延伸出无限参数试验。
