# 相场统一、20 秒视觉对照与逃逸分类检查

2026-10-23。Xue 要求先修正两套实现使用不同相场的实验问题，用同一场景重新做 20 秒视频，与第一次实验比较，然后继续分层核查和逃逸转换检查。本轮只使用小型二维测试，不读取或修改生产海浪缓存，不进行 Arnold 渲染。原实验和失败的检查目录全部保留。

## 第一层：统一的是什么

重新阅读并检查 PF-FLIP 原 PDF 第 7–8 页（§3.2–3.4）和第 15 页（§7）。相场采用 Eq.6 的原始质量沉积、Eq.7 的归一化／开方／截断，再执行液体相邻面置 1、空气相邻面置 0。代码中的 `phase_model=2` 已经具备这一实验实现；本轮修正的是完整喷雾实验的调用契约，让独立 NumPy 和真实 fused Bifrost graph 显式选择它，而不是继续各自使用不同默认公式。

纯相 cell 标签由另一次 cell-centre 质量沉积生成。这是明确记录的采样选择，论文未提供作者的确切 cell 采样实现，不能把它说成已经逐行还原作者代码。此次支持范围仍是 uniform 2D，无 ST、自适应、固体和外部造浪器。生产默认仍是旧模式，不能未经相应验证迁移。

解析值、纯相面邻接、六种实际 P2G 输入、两个模式的真实三步 graph 和不支持配置拒绝重新验证通过。六组相场数组误差均为零。原来的速度与动量是独立 float32 端口，Python 分别保存舍入前速度导出的动量，避免再次从已舍入速度构造动量。

新的完整实验保留 64×80 网格、初始 20,480 个粒子、同一 seed、dt≈0.0025、8,000 步、原发射／半径／阻力参数。C++ 前后只改变相场模式；原始 NumPy 对照还包含已知端口舍入纠正，所以不能把 NumPy 前后所有变化仅归于相场。

`visuals_phase_only/old_new_four_way.mp4` 上排为原实验，下排为统一后的结果，左 NumPy、右 C++；`cpp_before_after.mp4` 单独显示 C++ 前后。使用相同视野、像素标记、颜色和 1:1 模拟时间播放。每 0.1 秒取样，画面末帧约 19.9025 秒；数值检查另外包含真正 20 秒最终状态。

统一相场后的完整序列仍未通过原有相似性门槛。白色粒子也没有因此自动减少。**数学定义一致是必要条件，不能被宣称为已经修复后期运动。** 视频保留原貌，没有删掉难看的粒子或调整显示来掩盖问题。

## 第二层：基础运动、逃逸、辅助发射

三个独立双实现实验各运行完整 20 秒：基础两相流（逃逸和额外发射均关闭）、加入原逃逸／液滴规则、再加入原辅助发射。统一相场、时间步、FLIP 混合比例、初始粒子均相同。

基础流动的前 6 秒与此前 `plunge_pure_momentum` 的位置／速度输出完全相同：每个实现 120 个数组。因而此前同一路径的收紧容差、减半时间步检查仍适用，而不是将不同物理模式的结果混在一起。旧 6 秒检查亦没有通过高度尾部分布门槛；本轮不把这些敏感性试验称为已证明数学收敛。

开启辅助发射与只开逃逸相比，每个实现的 200 个保存状态及真正最终状态，主体位置、速度、类型、半径共 804 个数组逐位相同。这个场景中辅助白色粒子确实是被动的；它们增加视觉密度，但没有反过来改变主体运动。逃逸主粒子仍属于主体，不能与这些零转移质量的辅助粒子混为一谈。

基础两相流即使没有任何白色发射，完整独立求解也未通过原门槛。这将剩余稳定性工作定位到基础相场／投影／转移／推进组合，不能把全部问题归给发射器。

## 第三层：分类与运动切换

原代码根据对侧相粒子计数判断逃逸；论文 §3.4 则以相场位置值为候选条件，默认 delta_phi=.2，对应水粒子 phi<.3、空气粒子 phi>.7。两者不等价。

在统一相场的同一 C++ 缓存状态上，按平均双线性 MAC 面插值采样相场。约 3.2025、8.0025、18.0025 秒时，旧规则分别选择 40、103、275 个水粒子，相场规则分别选择 13、32、86 个。18 秒时旧规则所选粒子的相场中位数约 .726，最高为 1；275 个中有 220 个没有满足相场候选条件，另有 31 个相场候选没有被旧规则选中。这是具体模型差异，不是语言浮点尾数的别名。

新增默认关闭的 `escape=2` 作为分类实验；`escape=0/1` 保持原含义。它要求 `phase_model=2`、uniform 2D 和 0<esc_phi<.5。这里 `esc_phi=.3` 是水候选的下阈值，**不是**论文 delta_phi；空气和辅助喷雾回水使用上阈值 1-esc_phi。对称的回水阈值及 MAC 采样均明确属于本次实现选择。发射强度、粒径分布、阻力和发射候选计数仍保持旧值。

重要 C++ 改动只有新增选项的配置检查，以及从已有相场采样分类和回水。没有加 epsilon、迟滞或速度平滑，没有按这个场景调阈值。独立 Python 实现相同数学契约；七组常量／边界／线性场经过真实 C++ 节点验证，三组真实共同状态的分类完全一致，最大单步速度差约 1.91e-6 格/秒。共同状态重建一次动量并给两边相同输入，不是假称精确续跑。

半径分配自身没有修改速度。两条运动规则的差异出现在随后的 FLIP 更新与液滴阻力／位置积分之间；先前共同状态干预测得的速度差不等于“赋半径那一行直接跳变速度”。仍需考虑不同分支给出的加速度、推进和回水衔接。

新选项没有影响旧配置：原 legacy 短控制的 12 个数组通过；统一相场、原计数逃逸的完整 20 秒控制在改动前后，1,213 个数组逐位相同。五秒静水中同时打开新分类和辅助发射，检查两个实现整个序列的出生数，而非只看末帧。

静水两边累计出生均为 0，最终水 RMS 速度约 .009416 格/秒，水重心漂移约 .02499 格；最终位置差最多 3.81e-6 格、速度差 5.18e-7 格/秒。它通过通用静水控制，不代表撞水长序列也通过。

## 完整 20 秒验收结果

仍使用原预设门槛：4 格分箱水分布总变差 <.15、水重心差 <1 格、水高度第 99 百分位差 <4 格。下表取全部保存状态及真正最终状态中的最大差，不用末帧的偶然接近代替序列检查。

| 独立 NumPy／C++ 对照 | 水分布差 | 重心差，格 | 高度 P99 差，格 | 验收 |
| --- | ---: | ---: | ---: | --- |
| 统一相场，关闭逃逸／发射 | .12933 | 1.0413 | 7.0923 | 未通过 |
| 统一相场，只开原逃逸／液滴 | .13756 | 1.3433 | 16.5719 | 未通过 |
| 统一相场，原逃逸＋辅助发射 | .13756 | 1.3433 | 16.5719 | 未通过 |
| 统一相场，相场分类＋辅助发射 | .15367 | 3.1814 | 17.4629 | 未通过 |

四个 C++ 臂全部 8,000 步均满足请求的约 1e-6 真实压力残差。新分类没有解决长期独立求解的差异，不能以“更接近论文的分类”推导“整个方法现在稳定”。基础流动仍有约 2.7%–3.0% 的采样粒子机械能瞬态超调；完整喷雾模式的质量删除及阻力又使这项能量不是严格守恒量，不能混用成线性求解失败证据。

视觉上新分类末帧白点更少，但原因不能说成“少发射了错误粒子”。C++ 原计数规则累计出生 46,700、回水 24,157、蒸发 8,902，剩余 13,641；相场规则累计出生 **52,078**、回水 **43,235**、蒸发 4,068，剩余 4,775。两份独立 Python 也完成相同的生灭记账闭合。变化涉及整段轨迹和回水判定，不能从两个独立序列的总数单独分离各项因果。

第二轮视频 `visuals_escape_rule/old_new_four_way.mp4` 上排为计数分类，下排为相场分类，两排都使用统一相场；`cpp_before_after.mp4` 是相应 C++ 两路对照。不要与第一轮相场修正视频混为同一实验。

这些结果支持的下一优先级是：保持发射关闭，继续核查基础流动中纯相面系数切换、界面附近网格到粒子的速度传递与位置推进，以及体积漂移。当前证据尚不能在这些剩余项中指定一个唯一的完整修复。已有共同速度场回放表明两份粒子算法可精确重现同一轨迹，因此也不应继续笼统称为“Python 对 C++ 的语言问题”。

## 仍不能宣称完成的部分

新增 `escape=2` 是分类对应性的修正实验，不是完整生命周期重写。当前仍保留空气气泡的浮力／阻力模型，而论文说删除气泡；逃逸的主水粒子仍以原数值质量参与下次 P2G，辅助喷雾则为零转移质量。论文的“转为纯拉格朗日液滴”及再回水，需要进一步建立参与网格、代表体积、质量和半径的一致契约。半径不能未经论证地等同于该主粒子所代表全部水量。

其他已知缺口包括体积漂移校正，以及论文的水侧速度外推／局部 RK3 推进与当前默认路径的差别。已有试验没有给出足够验收依据，不能凭某一张图更平静就推广。此次不把新的分类或相场模式设为生产默认，不启动粗 3D 或新的生产海浪。
