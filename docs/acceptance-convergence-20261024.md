# 本轮调查的结论与停止条件

2026-10-24。Xue 指出调查持续扩张，要求重新收敛。本轮只区分三件事：
格子中心缺少粒子计数、速度面缺少采样、压力方程求解错误。没有改 C++、
修改生产参数、跑长模拟、渲染或删除数据。此记录是当前入口；下述未通过项
不因局部诊断成功而变成通过。

## 这次实际检查了什么

[测试脚本](../gates/audit_boundary_projection.py)先用原 DLL 复现旧飞行控制，
13 个最终状态数组逐位相同。随后在 16×12 的封闭二维空气域中，构造一个
数学上已知的非零旋转速度场。它满足墙面法向速度为零及零散度；再加入
一个已知压力梯度，要求实际 Bifrost 节点将它正确去除。一个独立组装的
NumPy 稠密矩阵解提供第二个判据，没有复用 C++ 压力程序。

这组试验**直接提供网格输入，刻意绕过 P2G**，用于隔离压力与密度修正，
不是完整流体、P2G 或粒子边界算法的验收。所有数值阈值在运行前固定。

| 仅改变的条件 | 实际结果 | 可以得出的结论 |
| --- | --- | --- |
| 完整采样，密度修正关闭 | 恢复已知速度场，最大误差 3.73e-9 格/秒 | 此受控场的壁面压力投影正确 |
| 完整采样，密度修正开启 | 网格速度与关闭时逐位相同 | 参考密度下修正不引入额外运动 |
| 移走一个墙边中心邻域的采样点，保留全部网格输入；修正关闭 | 网格速度仍与第一组逐位相同 | 中心计数为零不等于速度方程必然失效 |
| 同一个中心空采样，开启修正 | 明确拒绝 empty/nonfinite support | 失败发生于我们候选修正的定义域 |
| 完整中心采样，但将一个墙边内部速度面的输入质量与动量置零 | 投影后该面由输入 0 变为 -0.168863；正确值为 -0.263672 格/秒 | 压力会提供非零速度，但不会凭空恢复全部丢失信息 |

最后一组与独立矩阵投影的最大差仅 4.90e-8 格/秒，压力相对残差
8.29e-7；相对原来完整流场的最大误差却有 0.09481 格/秒。
这说明“方程解得对”与“输入足以恢复真实流动”是两个问题。
所有成功臂的墙面法向速度严格为零。完整记录见
[数值证据](../results/boundary_projection_20261024.json)。

第一次启动已复现旧控制，但单步测试包装 graph 没有暴露 `volume_tau`，
在求解之前被 bifcmd 拒绝。只给这个测试 graph 添加现有端口与连线，默认值
仍为零；没有改求解器。初次失败保留在
`out/runs/boundary_projection_20261024/check/`，完成的复验在 `check_r2/`，
耗时 25.29 秒。DLL SHA256 保持
`fb1eacf574587b391187887150a717506bf5d7f5fc0c6ed92a3d33efd61dc07b`。

## 到这里可以结束哪些调查

当前 `log(n/n_ref)` 修正要求每格 n>0。真实保留输入违反这个前提，
因此**当前全域正计数修正候选不适用于这些撞击状态**。这已经是一个确定的
否定结论，不需要继续寻找另一种语言误差、喷雾反馈或压力容差来解释它。
本轮不加 epsilon、不移动真实粒子、不替换核来让这个候选勉强通过。

两相主流体相互作用与被动小液滴读取空气速度是不同层次。
旧主液滴影响空气的事实不是所有双向耦合错误的证明；现有辅助液滴也不是
因此需要参与压力求解。已经通过的受控喷雾子项保持其有限结论，不重复推翻。

没有证据足以把旧 20 秒视频的后半段运动全部归因于墙边缺采样。
本轮也没有证明真实 P2G 在墙边的精度已经合格。这个未证实的因果猜想保留为
观察项，**不自动另开完整边界重写或新的文献调查**。是否需要修补，必须由
固定完整物理测试中的失败及可复现反例触发。

## 剩下的工作按固定交付物结束

沿用 [五步路线](verification-route.md)，不是再增加第六、第七步。
当前最先需要选择的模型只有主流体稀疏采样下的密度修正；几何体积测量的
标定和最终长程行为仍是已知必需验收，不被隐去。

1. **选定一个可检验的基础流动候选。** 写清楚数密度采样、稀疏/零支持、
   墙面、删除/转换及闭域目标散度的规则，说明数学依据和实现近似；同时
   固定几何体积的测量分辨率与误差预算。只选一个候选，不并列试一串参数。
   当前失败的全域正计数公式保留为反例；简单关闭修正不能冒充该条款完成。
2. **让该版本通过已有的小验收组。** 用三个已保存的撞击输入检查适用域，
   同输入 NumPy/C++、独立压力/密度见证、静水、材料账与几何测量、转换/回水、
   喷雾计数/粒径/阻力/蒸发和续跑。通过且未改动的独立模块复用已有证据；
   集成或二进制变化影响到的检查才重跑。沿用已有数值门槛。
3. **冻结版本，做一次完整二维撞击恢复及一个留出场景。** 前置检查全部通过
   才启动；保留旧长轨迹和视频。按事前指标判断稳定性、体积变化、能量和
   喷雾生命周期，不要求长期混沌轨迹逐粒子重合。通过才提交二维验收报告，
   与 Xue 讨论粗 3D。

每轮必须以“通过”“该候选失败”“证据不足及具体缺少的测量”之一结束。
某项失败后最多两次限定范围的因果诊断；若仍不能闭合，停止该候选，交付
最小反例和未满足的指标，先重新讨论路线，不能自动增加第三种算法、调阈值
或再跑一轮大模拟。仪器/包装修复须单独记录，不得算作物理模型通过。

这个结束条件不保证下一候选必定成功；它保证失败也是有边界的研究结果。
目前没有完整二维验收证书，也没有准入粗 3D；现有 40 秒 cache 继续保留。
